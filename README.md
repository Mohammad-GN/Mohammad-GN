## 📐 Theoretical Framework

### Ionic Hubbard Model

```math
H =
-t\sum_{\langle i,j\rangle,\sigma}
\left(
c_{i\sigma}^{\dagger}c_{j\sigma}
+\mathrm{h.c.}
\right)
+
U\sum_i n_{i\uparrow}n_{i\downarrow}
+
\frac{\Delta}{2}\sum_i(-1)^i n_i
```

### Continuous Unitary Transformations

```math
\frac{dH(s)}{ds}
=
[\eta(s),H(s)],
\qquad
\eta(s)=[H_0(s),V(s)]
```

These flow equations provide a framework for transforming interacting Hamiltonians into effective forms suitable for studying low-energy excitations and spectral properties.
